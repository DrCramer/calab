Calab is open to integrations in three ways.

## Bots and API

Server integrations with a bot token — see the [quickstart](../bots/quickstart).

## OAuth 2 / OIDC

“Sign in with Calab” for your service — the [Authorization Code flow](../oauth/flow).

## SSO and directory

Employee sign-in through your corporate IdP — [connecting OIDC](../sso/oidc).

```http
GET /api/version HTTP/1.1
Host: app.calab.io
```
