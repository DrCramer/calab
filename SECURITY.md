# Security policy

Please report vulnerabilities privately to support@calab.io (or via GitHub private vulnerability reporting) — not in public issues.

We aim to acknowledge within 3 business days and to ship a fix for confirmed high-severity issues within 14 days.

Supported: the latest released version on `main`.

Scope includes the Go API/gateway, the Electron and web clients, and the deployment configs in `infra/`. LiveKit, Caddy, PostgreSQL and Redis are upstream projects — report their issues upstream.
