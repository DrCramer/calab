# ADR-0115: Почта — боковая колонка ящиков, правка папок и умные папки (2026-10-22)

**Статус: принято.** Дополняет [ADR-0088](0088-mail-client.md) §7–§8. Задача CBF-56 (владелец в чате, 22.10).

## Контекст
В ADR-0088 §8 навигация по ящику — только переключатель «Входящие ⌄» над списком: плоский лист всех папок всех
ящиков. При двух ящиках он длинный и повторяет одни и те же «Входящие/Отправленные…»; папку можно только создать
(CBF-39, из настроек), переименовать и удалить — нельзя. Владелец хочет как в Apple Mail: слева ящики со своими
папками, своя папка внутри ящика, правка и удаление, «умные» папки по правилам.

## Решение
1. **Боковая колонка** (`MailSidebar`) слева от колонки списка, скрываемая (кнопка в шапке; запоминается на
   компьютере): «Избранное» (только при нескольких ящиках: «Все входящие», «Все: Отмеченные»), затем каждый
   ящик — сворачиваемая группа с деревом папок (`folderTree`: роли сверху в порядке Apple Mail и никогда не
   вложены, свои папки по имени, подпапки под родителем по `parentId`), затем «Умные папки». Переключатель
   над списком остаётся, но группирует: «Все …», затем ящики подменю со своим деревом.
2. **Правка папок только на сервере, без очереди.** `folders.rename` (IMAP RENAME, подпапки следуют, строка
   папки и id писем не меняются) и `folders.remove` (IMAP DELETE подпапок, затем самой; письма удаляются
   локально). Только свои папки (без роли). Офлайн — `NETWORK` и понятный тост, ничего не меняется. Правила
   сортировки переезжают за переименованной папкой и удаляются вместе с удалённой. Удаление — с подтверждением.
3. **Умные папки — локальный вид**, на сервере ничего не создаётся: `settings.smartFolders` (`settings.sqlite`,
   без новых таблиц) — имя, ящик или все ящики, «все условия / любое условие», до 10 условий «Отправитель /
   Получатель (Кому+Копия) / Тема содержит X». `messages.list` с `folder: { smart: id }` отбирает уже
   загруженные письма всех папок ящика, кроме Спама и Корзины. Сопоставление — одна чистая функция
   `shared/mailMatch.ts` (её же используют правила сортировки CBF-39 и мок); в SQLite она подключена как
   функция `mail_smart(...)`, потому что встроенный `lower()` понимает только ASCII. Новые письма появляются
   в открытой умной папке по событиям, если совпали по отправителю/теме (строке списка адресаты неизвестны —
   условие «Получатель» срабатывает со следующей загрузки списка).

## Альтернативы
- **Умная папка как IMAP-папка с правилом-перекладчиком**: дублирует письма или уносит их из Входящих —
  отклонено владельцем («правила не должны дублироваться в IMAP-папку»).
- **Очередь переименования/удаления офлайн**: конфликт с изменениями на других устройствах и неясный откат;
  папки меняются редко — проще честно сказать «нет связи».
- **Фильтр умной папки в renderer по загруженной странице**: неполный (страница = 50 строк) и без
  пагинации; SQL-отбор в движке даёт обычный список с курсором.
