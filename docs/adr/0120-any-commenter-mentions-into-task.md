# ADR-0120: Упоминание в комментарии задачи зовёт наблюдателя без права правки (2026-10-22)

**Статус: принято.** Меняет [ADR-0076](0076-task-watchers.md) §4–5 только для @упоминаний в комментариях.
Задача CBF-53, решение владельца 22.10.

## Контекст
По ADR-0076 §4–5 упоминание делало наблюдателем, только если автор комментария может править задачу:
иначе позванный со стороны мог бы звать дальше по цепочке. Владелец (22.10): любой участник задачи
может призвать пользователя через @ в комментарии; остальные права на задачу не расширять.

## Решение
1. **Кто зовёт.** Любой, кто может написать комментарий в комнате задачи (`SEND_MESSAGES` по
   `perm.TaskRoom`: видит доску или участник по карточке, задача не в архиве, комментарии включены,
   пространство не приостановлено). Право правки не нужно. Гости досок не видят и комментировать не могут.
2. **Кого.** Без изменений (`mayMention`): участник пространства, не гость, не бот, на живой доске;
   ≤ 50 упоминаний в сообщении, ≤ 50 наблюдателей на задаче. Упоминания из пересланного сообщения и из
   цитаты при «Задача из сообщения» по-прежнему не зовут.
3. **Что получает позванный** — то же, что наблюдатель по ADR-0076 §3: `VIEW_BOARD` на эту карточку
   (смотреть, комментировать, подписываться); правки, журнала, настроек доски нет.
4. Явное добавление наблюдателя (`PUT …/watchers`), исполнители и согласующие — как прежде, только
   редактор задачи (ADR-0076 §4).

## Последствия
- Цепочка возможна: наблюдатель по карточке может позвать следующего. Это принятая цена (владелец);
  граница — 50 наблюдателей на задачу, снять может редактор.
- Бот с `VIEW_BOARD` на доске, пишущий комментарии, тоже зовёт упоминанием.
- Клиент больше не показывает «Позвать может тот, кто правит задачу»; сервер проверяет сам.

## Альтернативы
- **Оставить право правки** — противоречит решению владельца.
- **Звать только видящих доску** — не решает задачу: участник по карточке не смог бы позвать коллегу.
