# Холст v2 — задачи

ADR: [0114 Холст — вторая итерация](../adr/0114-canvas-v2.md) (расширяет [0113](../adr/0113-canvas.md)); v1 — [canvas-v1-tasks.md](canvas-v1-tasks.md). Ветка интеграции — `feat/canvas`; задачи — в своих worktree и ветках, лид мержит в `feat/canvas`.

Решение владельца (20.10): делаем волны 1–5; рисование от руки и картинки откладываем.

**Исполнение — строго по одной сессии за раз.** Параллельные сессии перегревали процессор владельца (load average 78). Правила нагрузки для каждой сессии: все тяжёлые команды через `nice -n 19`; в цикле только тесты затронутых файлов (`vitest run <файлы> --maxWorkers=2`); полные `pnpm -r typecheck`, `pnpm -r lint`, `pnpm -F @calaba/desktop test` (и для серверных волн `golangci-lint` + интеграционные тесты пакетов) — по одному разу в конце и последовательно; никаких фоновых процессов после себя; стенд владельца (БД `calaba_demo`, Redis DB 5, порты 3090/5190) не трогать.
