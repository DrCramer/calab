## 2. Позиционирование

**Выбранный вариант**

- RU, заголовок: **«Вся работа команды — в одном окне.»**
- RU, подзаголовок: «Голосовые комнаты, чат, встречи, задачи, вики, холст, диск, почта и телефония. Всё связано между собой и работает в облаке или на вашем сервере.»
- EN: **“Your team’s whole workday in one window.”** — “Voice rooms, chat, meetings, tasks, wiki, canvas, files, mail and phone calls — connected to each other, in the cloud or on your own server.”

Почему: отвечает на «что это» за 2 секунды, перечисление — само доказательство «как много всего», «связано между собой» — ключевое отличие от набора сервисов, «на вашем сервере» — главный аргумент для РФ-рынка. Совпадает с README («Your whole team in one window»).

**Альтернативы**

1. «Вся команда. Рядом.» (текущий) — эмоционально, но не называет категорию продукта; читатель должен скроллить, чтобы понять, что это. Отклонён.
2. «Одно окно вместо семи подписок» — сильный аргумент для того, кто платит; минус — звучит как «дешёвый заменитель», не говорит о голосе и своём сервере. Используем как заголовок секции 3, не hero.
3. «Пространство, где слышно команду» — верно про voice-first, но узко: не видно задач, вики, телефонии. Отклонён.
4. «Discord + Linear + Notion + Miro + АТС — на своём сервере» — максимально понятно, но чужие торговые марки в hero: юридический риск и зависимость от чужих брендов. Отклонён (в тексте можно писать категории: «мессенджер, трекер задач, вики, доска»).

**Для кого.** Команды 10–500 человек, у которых сейчас зоопарк: мессенджер + видеозвонки + трекер + вики + доска + диск + облачная АТС. Три сегмента, каждый получает свою «точку входа» на странице: (а) руководитель/владелец малого бизнеса — секция «вместо семи сервисов» и тарифы; (б) ИТ-директор/безопасник — «Под вашим контролем» (свой сервер, SSO, роли, BSL 1.1); (в) разработчик/интегратор — страница «Разработчикам» (боты, MCP, SDK, вебхуки).

## 4. Информационная архитектура главной

Правило порядка: продукт → доказательство связности → полный каталог → специализированные блоки → доверие → цена → скачать → FAQ. Цель по длине: ≤ 12 000 px на 1440 (сейчас 18 761), ≤ 15 000 на 390.

### 0. Header
Логотип · Возможности · Телефония · Разработчикам · Тарифы · Скачать · [глобус] · **Открыть в браузере**. Фон — сплошной `#0b0b0b` на всю ширину (убираем прозрачный бар: контент не проходит под остров). Высота 72 px.

### 1. Hero — «одно окно, семь сцен»
- H1: «Вся работа команды — в одном окне.» (живой заголовок остаётся: Source Serif 4, хвост «в одном окне» — курсивный акцент; на десктопе две колонки: слева заголовок, лид, кнопки и платформы по центру по вертикали, справа окно приложения в перспективе с выходом за край страницы и лёгким наклоном за курсором; тихие пилюли сцен под героем; на телефоне — столбиком). Лид — подзаголовок из §2. Кнопки: «Скачать» (синяя), «Открыть в браузере» (белая). Строка «macOS · Windows · Linux · Web · телефон».
- Визуал: окно приложения 1200 CSS px шириной (кадр 1440×900 @2x, тёмная тема), рамка `.shot-frame` r16, без тени. Под ним ряд из 7 чипов-сцен с иконками из рейла: Голос (`voice` — стрим + камеры, сцена-LCP), Чат (`chat-full` с карточкой задачи), Задачи (`kanban-full`), Календарь (`calendar-week`), Вики (`wiki-full`), Холст (`canvas`), Телефон (`phone-call`). Подпись к активной сцене — одна фраза (например, Голос: «Зашли в комнату — и уже слышите коллег. Экран, камеры, указка поверх стрима»).
- Анимация: кроссфейд 250 ms; при появлении в viewport один конечный проход по первым трём сценам (по 3,5 с), останавливается после прохода, при любом действии пользователя и при `prefers-reduced-motion`. Стикеры за курсором (`quiet`) остаются. Клавиатура: чипы — `role="tablist"`, стрелки.
- Телефон: окно заменяется фокус-кропом сцены 720×560 (центральная панель), чипы — горизонтальный скролл.
- CTA: те же две кнопки; третьей нет (место под «Попробовать демо» — идея 7).

### 2. «Вместо семи сервисов — одно окно»
- H2: «Вместо семи сервисов — одно окно». Лид: «Мессенджер, видеозвонки, трекер задач, вики, онлайн-доска, диск, почта и телефония — у команды обычно это семь вкладок и семь счетов. В Calab это один рейл слева.»
- Визуал: слева ряд из 8 «вкладок браузера» с подписями-категориями (без чужих логотипов), справа — вертикальный рейл Calab (реальные иконки: Команда, Личные, Календарь, Доски, Почта, Вики, Холст, Диск, Телефония) 200 px высотой. При появлении секции вкладки схлопываются в рейл (CSS-анимация 600 ms один раз; reduced motion — статично).
- Текста минимум, высота ≤ 560 px.

### 3. «Всё связано между собой» — один день команды
- H2 «Один день команды — не выходя из окна» — только для скринридеров (владелец, 24.10: секция начинается сразу с шагов, лида нет). Был лид: «Сообщение становится задачей, у задачи появляется встреча, встреча оставляет запись и расшифровку, итог — на странице вики и на холсте. Всё ссылается друг на друга.»
- 8 шагов, вертикальная лента (каждый шаг — ~треть экрана прокрутки, активный — тот, чей текст пересекает середину экрана): слева текст шага (заголовок 26 px + 1 фраза), справа кроп (сменяется при скролле через IntersectionObserver, на телефоне — просто подряд). Сквозная нить — задача **APP-7 «Экспорт доски в CSV»** команды «Нордлайт»:
  1. «Из сообщения — в задачу» — `story-message` (сообщение Веры Ким с hover-действием «В задачу»).
  2. «Задача с чек-листом и согласованием» — `story-task` (панель задачи, ссылка «из сообщения», исполнитель, срок, чек-лист 2/4, согласующий).
  3. «Встреча прямо в комнате» — `story-meeting` (карточка события «Ревью экспорта», комната «Переговорка», кнопка «Перейти»).
  4. «Запись и расшифровка — в чат» — `story-recording` (карточка записи: сводка, аудио, «Расшифровка»).
  5. «Итог — на странице вики» — `story-wiki` (страница «Экспорт в CSV» со ссылкой на задачу и карточкой холста).
  6. «Файлы — на облачном диске» — `disk-panel` (плитки диска команды).
  7. «Ретро — на холсте» — `canvas-panel` (сам холст: стикеры по колонкам, голоса, таймер, курсор коллеги).
  8. «Звонок клиента — прямо в Calab» — `story-incoming` (окно входящего звонка на номер группы «Продажи»; кроп из `phone-incoming`).
- Анимация: появление кропа — opacity+translateY 8 px, 350 ms, один раз.
- CTA в конце: «Все возможности ↓» (рисованное подчёркивание, тот же стиль, что сейчас у «Все возможности»).

### 4. «Что есть в Calab» — каталог
- H2: «Что есть в Calab». Лид: «Каждый кадр — настоящее приложение в тёмной теме, ничего не дорисовано.» (теперь это правда: кропы без `object-cover`).
- Десктоп: слева sticky мини-рейл (идея 8) — иконки 4 групп, клик скроллит к группе; справа сетка плиток **одного размера** 16:10 (две колонки, ширина 620 px) и широких плиток 2:1 на всю ширину (одна на группу). Телефон — одна колонка.
- Группы и плитки (кадр → состояние):
  - **Общение**: широкая «Голосовые комнаты и экран» (`voice`), «Видеовстречи» (`gallery`), «Чат, как в Telegram» (`chat-focus`: реакции, ответ, стикер, карточка задачи), «Звонки на телефон» (`phone-call-focus`), «Временные комнаты и гости» (`temp-room`: диалог временной комнаты с гостевой ссылкой — новое), «Запись и расшифровка» (`recording-focus` — новое).
